# Fixed model acceptance matrix

The fixed corpus contains 64 rows and is evaluated three times per explicitly selected planner/reviewer configuration: 192 trials. Group counts are planner grounding 12, runtime review 20, adversarial strings/JSON 12, failure/context/capability 12, and diagnostic/visual comparison 8. Each row points to a repository-relative immutable fixture descriptor and states expected admitted/rejected/preflight-rejected result, exact structured status or failure code, required and prohibited JSON-pointer values, and an evidence reference. Critical seeded defects name the case ID in `observedDefects` for every repetition. The corpus author fixes these expectations before live evaluation.

The runner sends each row to its configured profile. Planner and diagnostic rows use `plannerProfileId`; runtime reviewer rows use `reviewerProfileId`. The trusted adapter records an actual model call immediately before transport invocation. Every non-preflight row requires exactly one observed call. Preflight rejection requires zero. A callback's own call count must match observation. The runner fails profile substitution, malformed binding/schema/check sets, prohibited action, positive false blocks, invalid or missing evidence, false accepts, missing defect detections, duplicate/missing cases, and a missed deadline. It records cold and warm median, p95, worst, output tokens, failures, false accepts, and false blocks. All observed calls, including failed trials, enter the timing report. A p95 at or above 80% of configured deadline fails the margin target.

`provenance: synthetic` is a harness test result only. It cannot become a live model or release qualification. A positive corpus result means the fixed finite cases passed; it does not establish perfect model behavior. The mandatory host checks and actual image review remain separate.

The current synthetic harness tests construct the 64 row layout and exercise 192 trials. The parallel corpus packet supplied `tests/intelligence/fixtures/acceptance-corpus.json` and 64 case descriptors, including 27 visual bundles. The runner validated its group counts and schema; live candidate results are unrun. The unchanged corpus must be run against each exact candidate artifact/runtime/prompt/policy before promotion.
