# Deterministic image QA contract

`inspectImageQuality` consumes three retained artifact byte copies, the exact `OutputSpec`, a qualified template policy, a retained color-export trace, and an optional retained reference image. The caller obtains bytes from the C4a verified evidence snapshot. It must verify the snapshot's manifest closure, current job/asset/attempt/profile/template bindings, and trace file digest before invoking QA; a caller-created `qualified: true` policy or proof record is not qualification evidence. The QA function checks its own policy digest, output binding, artifact/trace digests, and each trace proof's artifact/profile/template/backend qualification/transform binding. The color trace format for this internal boundary is UTF-8 JSON `{ "colorExports": [ColorExportProof, ColorExportProof, ColorExportProof] }`, with exactly IDs 1, 2, 3. C4a or A must extract this from a qualified backend export trace and seal it. Image profile metadata alone cannot satisfy color proof. The current C4b code cannot independently authenticate the backend trace producer; integration must bind it to a qualified backend and sealed attempt.

Policy is template-specific and self-digested with `policySha256 = sha256Json(policy without policySha256)`. It states exact output dimensions and format, `maxInputBytes`, `maxPixels`, `maxDecodedBytes`, qualified RGB background and foreground distance, alpha threshold, and one or more qualified metric limits. Missing or invalid policy fails. Pixel measures use Sharp 0.35.4 decoded sRGB RGBA samples. Foreground means alpha at or above the policy threshold and maximum RGB-channel distance from the qualified background at or above the policy distance. Alpha/foreground fractions use complete output pixels; ROI uses exact output pixel coordinates. Preservation compares normalized RGBA pixels against a retained reference capture in a qualified region. Sentinel checks compare each variant to the other two in a qualified region only when configured. Thus flat-color foreground, contain margins, stretch distortion, and intentionally similar or identical exports can pass an appropriate qualified policy.

Bounds are enforced on retained compressed bytes, declared output pixel count, decoder `limitInputPixels`, decoded RGBA byte count, and single-page metadata before metrics. Full decoding uses `failOn: error`; wrong media format and dimensions fail. `reasons` contain deterministic codes and never claim visual correctness. Report records decoder and libvips versions, actual input/reference/trace digests, thresholds, per-variant metrics, and failures. QA is a deterministic gate; C4c visual review remains separate.

The license-free fixtures in `tests/intelligence/fixtures/artifacts/` are generated by `generate.mjs`; `digests.json` records their byte lengths and SHA-256 values. Regenerate under pinned Node 22.23.2 and Sharp 0.35.4 only when fixture semantics change.
