# B15-R5 asset inventory producer — 2026-09-30

Status: **implemented-and-fake-tested** for the read-only v2 producer. This is not a complete B v2 backend or live Photoshop qualification. It consumes A's shared v2 contracts from B commits `e11a521` and `4a82b43`; no local wire schema or second installation lock was added.

`prepareOwnedInputV2(request, scanner, signal)` resolves the selected asset under the exact canonical source root, recomputes A's SHA-256 `realpath|dev|ino` identity, and measures actual source bytes. PNG/JPEG files must strictly decode and prove an empty PSD-style link closure without calling the scanner. PSD/PSB files require a qualified, read-only scanner whose result binds `sourceSha256`, `complete: true`, and explicit links to the measured bytes. Linked PSD/PSB files are scanned recursively; linked rasters are decoded. Missing, unknown, changed, cyclic, symlinked, out-of-root, identity-mismatched or unsupported sources return the shared `status: blocked` manifest with a typed error. An unchecked empty scanner array cannot qualify a PSD/PSB.

A prepared result includes each unique dependency's original `FileRef`, byte count and stable path-derived identity, with `closureComplete: true`. B writes canonical observed closure bytes to `checks/asset-closure.json` under the existing attempt staging root, returns their SHA-256 in `closureProof`, and persists the exact shared manifest at `checks/prepared-input-manifest.json` with exclusive writes. The backend can reread that file under its own lock before admitting render; an old or reused operation cannot overwrite either proof. The exported `sourceRootIdentity` helper lets the backend recheck the same A root binding. This producer never copies/relinks source files, opens Photoshop, or releases a lock. A copies the inventory under the reviewed v2 request; B's backend wrapper must independently verify the owned bytes/closure before mutation.
