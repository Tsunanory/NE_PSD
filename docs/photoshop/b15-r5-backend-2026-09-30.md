# B15 R5 V2 backend checkpoint

`PhotoshopBackendV2Adapter` now implements V2 preparation, render, and recovery under one `SessionLock`. The tested path is a strictly decoded PNG/JPEG source. PSD/PSB source preparation returns `LINK_SCAN_UNAVAILABLE` because this checkout has no code-owned, installation-qualified read-only PSD linkage scanner. A caller-supplied empty link list is not accepted as a substitute. No live Photoshop or Windows qualification was run.

Render rereads the persisted prepared manifest and digest-bound asset closure; remeasures source-root identity, original bytes and A-owned copy bytes; and opens only the verified owned source. It creates a separate template working copy, checks the renderer's opened paths, canonical trace files and artifact bytes, and writes shared-schema owned-input and template-closure proofs. Exact recovery context and owner/journal snapshots persist outside the lock directory. Release proof and V2 evidence are written only after `runExclusive` confirms lock release. Recovery requires the exact persisted attempt identity and retained journal, runs `recoverJob`, and returns `safe: true` only after confirmed release and durable proof. Unknown or mismatched state returns `safe: false, released: false, releaseProof: null`.

The working-copy attempt root is canonicalized after creation, so macOS `/var` to `/private/var` aliases cannot invalidate an otherwise confined copy. The canonical parent check still rejects a substituted attempt directory.
