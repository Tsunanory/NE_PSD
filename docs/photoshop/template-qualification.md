# Template qualification boundary

Inspection is read-only evidence. It snapshots the selected template before traversing child documents, records pre-existing document IDs, and closes only documents opened by inspection without saving. User-open documents are never closed. Reports distinguish raw raster bounds from effective live bounds. Shape/vector layers may have zero raster bounds while Photoshop reports a non-empty effective rectangle. The supplied child canvas is expected to be `3190 × 1418`; the reference shape's effective bounds are `{left:100,top:200,right:900,bottom:600}`.

Unknown or missing linkage remains `sourceKind: "unknown"`, is recorded in `unresolvedLinks`, and blocks qualification. Static inspection and unresolved links never reach rendering. Live qualification reads capabilities again inside the existing installation lock and requires an exact identity/tool-schema/backend/version/mode match with the inspection report plus explicit acknowledgement.

The flow is `InspectionReport → ConfigurationProposal → QualificationRequest → QualificationResult`. Qualification never calls `render` and never accepts or constructs a sealed `TemplateProfile`. It creates a fresh B06-style working copy with closure evidence, original-digest verification and mandatory transaction/copy cleanup. Master and every linked source are hashed before and after operations. Paths are canonicalized under explicit approved template/evidence roots; symlink escapes and outside working copies fail closed.

Preparation is explicit. A changed copy requires positively acknowledged save and reopen before hashing and selector resolution. Selectors are regenerated against the prepared SHA and returned with proof for every target, reference, input and variant candidate. Falling back to inspection selectors is blocked. Already-prepared copies require an explicit acknowledged no-change proof.

When preparation changes the candidate bytes, the qualified candidate is retained under a fresh `evidenceDirectory/prepared/` directory before scratch cleanup. The retained copy is built from a byte-bound, complete link scan; linked resources are copied and relinked or embedded only through acknowledged operations. The retained master and every closure member are rehashed, selectors are resolved again against the retained master, and both the retained closure and original sources are checked after scratch cleanup. An existing destination, unavailable or changed scan, unknown link, outside closure member, tampered retained file, or ambiguous mutation blocks qualification without overwriting the prior evidence.

Clipping inspects exact sibling order, parent, adjacency, clipping base, mask semantics, holes, effects, outer transform, layer count and name uniqueness. Move, preparation and clipping mutations require `acknowledged:true`; uncertain replies retain the recovery barrier. A correct retained relation performs zero mutations. Pixel preparation is at most once and is reread for idempotence.

The sentinel is a deterministic transparent PNG with four asymmetric corner colors and a white center cross. The qualifier decodes every exported variant with Sharp and verifies orientation, alpha holes, center cross, coverage, distinct variant bytes and actual files. Visibility is switched and reread for each variant. Resource identity routes are explicit; shared resources are written once, independent resources separately, and every write/save/reopen is acknowledged. Booleans and arbitrary bytes are not evidence.

Evidence contains actual pre/post snapshots, checks, sentinel source, source-integrity closure digests and all three exported image paths. Qualified evidence paths are relative, existing and confined to the approved evidence root. Blocked results cite only existing evidence and never fabricate passed checks.
