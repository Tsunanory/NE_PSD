# Task 3 evidence bundle and automated review gate

Status: implemented and tested on synthetic staged PNG bytes. No Photoshop, Windows, local Qwen, or live vision qualification is claimed.

`buildEvidenceBundle` requires actual staged source bytes, three explicitly qualified reference files, the three current exports, and at least one pixel-matched detail crop per export. It records render evidence, document/tool traces, producer check files, and every V2 proof dependency: owned input, linked closure, template closure, release, retained owner/journal snapshots, and retained working copies. Each manifest entry binds a relative path, byte count, role, and SHA-256. It rejects symlinks, path escapes, filename collisions, missing files, forged reference qualification, mismatched derivation, and changed bytes. `verifyEvidenceBundle` rehashes the staged files; `bundleDigest` is the shared canonical manifest digest.

`gateAutomatedReview` resolves the persisted planner and selected reviewer profiles, compares both profile digests to the persisted transaction bindings, and requires a qualified vision-capable reviewer. The review policy must match the job digest and contain all 15 mandatory requirements. Independent artifact QA results are authoritative for exactly-three, decoding, dimensions/color, and calibrated image quality. Unqualified image quality remains `unknown` and blocks. Other mandatory deterministic results require independently validated B proof plus A persistent-state results; absent, failed, or unknown results block before inference. The model cannot promote those results. A passing decision must match current job/asset/attempt/evidence digest, selected model/provenance, prompt/policy, unused session, all mandatory checks, and three individual output passes. Bundle bytes and bound input objects are checked before and after review. Reviewer outage returns `pendingReview` with the original staged bundle path and digest for a new review session without rerender.

Integration dependency: `IntelligenceService.review` and C's evidence validator must accept the complete V2 render evidence. A minimal additive `ReviewEvidence` V1/V2 union is prepared in shared contracts. C's current validator still assumes V1 render evidence and rejects V2 proof files that are not base render checks. C must validate all V2 proof and owner/journal snapshot references as ordinary closed manifest files, without synthetic check IDs or stripping V2 fields. The shared union commit is pending authorization after automatic approval review rejected the worker's commit; source and tests remain intact.

Validation: focused evidence/review tests use real temporary PNGs and cover staged byte drift, missing vision evidence, qualification mismatch, crop forgery, symlink escape, selected-profile/provenance/prompt/session mismatch, unknown mandatory QA and proof results, one failed variant, and reviewer outage. V2 closure regression checks owner-snapshot drift. Tests do not establish live Photoshop geometry, linked propagation, release ownership, or model visual accuracy.
